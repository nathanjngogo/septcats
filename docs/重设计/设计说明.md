## 1. 三个方向（同一套信息架构，只在"材料/字体/色彩/圆角/动效"上分道）

三个方向都是**你的真实 IA**：一级轨八项（笔记/知识库/日历/多维表/待办/工作台/模板/回收站）、顶栏纯中文钮、三屏（编辑器 / 多维表格看板 / 日历+待办）。这样你比的是"气质"，不是"结构"。

### 方向 A · 印刷所（Editorial Press）
- **立场**：知识库 = 出版。界面是纸，不是玻璃。编辑器是本次重点。
- **材料**：纸纹噪点（SVG feTurbulence，零外部资源）+ 双线分隔（3px double）+ 零模糊、零投影。
- **字体**：正文/标题走**衬线**（Georgia / 思源宋体），小标签走等宽大写字距。
- **色彩**：纸白 `#F7F3EA` / 墨黑 `#14110C` / **朱红 `#C2402A`**（活动）/ 靛蓝 `#1F3A5F`（日程）/ 青 `#2E7D8F`（同步）。
- **特色**：标题的"**套印不准**"（1px 蓝青错位描边）、首字下沉、边注栏、刊物页码（No.12）、目录式侧栏（§ 符号）。
- **圆角** 0–2px｜**动效**：几乎为零（纸不动），只有下划线扫入。
- **最适合**：笔记/长文为主的重度写作者；最省性能（无 backdrop-filter）。

### 方向 B · 夜航仪表（Instrument Dark）
- **立场**：工作台 = 仪表盘。界面按"读数"组织，不按"装饰"组织。
- **材料**：实色层 + 1px 内发光边 + 极淡扫描线（2% 白）+ 网格刻度；**零模糊、零渐变**。
- **字体**：**等宽为主**（Consolas / JetBrains Mono，数据必须对齐），中文走无衬线。
- **色彩**：底 `#080B0E` / 面 `#111820` / **荧光青 `#35E0C8`**（活动、在线）/ 琥珀 `#FFB43A`（注意）/ 红 `#FF5A5F`（阻断）/ 紫 `#9C8CFF`（已完成）。
- **特色**：顶栏是三格**读数**（同步/待办/写作量）；文档右栏是**遥测**（写作节奏、双链密度、容量、火花线）；看板列头带计数、阈值色条（>5 转琥珀、>9 转红）；文件编号 `DOC-2481`；块/链接/附件计数。
- **圆角** 2px｜**动效**：点亮/熄灭两态，数字滚动。
- **最适合**：数据/多维表格/工作台为主的重度用户；夜景与长时间盯屏最省眼。

### 方向 C · 新粗野（Neo-Brutalist）
- **立场**：界面是**实体积木**。不做错觉：无模糊、无渐变、无半透明。边框即结构，硬影即层次，撞色即语义。
- **材料**：2–3px 纯黑硬边 + 6–10px **偏移实心影**（零模糊）+ 纯色块 + 32px 网格纸背景。
- **字体**：超粗无衬线（Inter/雅黑 Heavy），负字距大标题；标签等宽大写。
- **色彩**：奶油 `#FFFDF5` / 纯黑 `#0B0B0B` / **电光黄 `#FFE600`**（活动）/ **钴蓝 `#2B4CFF`**（进行）/ **番茄红 `#FF4B3E`**（阻断/关闭）/ 薄荷 `#7BF1A8` / 紫 `#C9A0FF`。
- **特色**：贴纸式标签、按下即位移（60ms 阶跃，无缓动）、侧栏选中项带"▶"指示、看板卡片自带「移到」硬按钮（与本次已修的键盘可达路径同构）、窗口关闭钮悬停变红。
- **圆角** 0（唯一的圆是状态点）｜**动效**：硬切位移。
- **最适合**：要高辨识度、要在截图里"一眼认得出"；信息密度最高、扫读最快。

## 2. token 草案（可直接映射到本仓 `--sc-*` 体系）

| 语义 | 现仓 token | A 印刷所 | B 夜航仪表 | C 新粗野 |
|---|---|---|---|---|
| 画布 | `--sc-color-canvas` | `#EFE9DB` | `#0C1116` | `#EDEAE0` |
| 内容底 | `--sc-color-content` | `#F7F3EA` | `#080B0E` | `#FFFDF5` |
| 面 | `--sc-color-surface` | `#EFE9DB` | `#111820` | `#FFFFFF` |
| 主文字 | `--sc-color-ink` | `#14110C` | `#D3DFE7` | `#0B0B0B` |
| 次文字 | `--sc-color-ink-secondary` | `#4A4237` | `#8B9BA8` | `#26241C` |
| 弱文字 | `--sc-color-ink-faint` | `#8A8071` | `#5C6B77` | `#6E6A5C` |
| 主色 | `--sc-color-accent` | `#C2402A` | `#35E0C8` | `#FFE600` |
| 主色淡底 | `--sc-color-accent-soft` | `#F0DCD6` | `#12302E` | `#FFF7B0` |
| 危险 | `--sc-color-danger` | `#C2402A` | `#FF5A5F` | `#FF4B3E` |
| 圆角 | `--sc-radius-*` | 0 / 2px | 2px | 0 |
| 边框 | `--sc-border-edge` | 1px `#14110C` | 1px `#22303C` | 2–3px `#0B0B0B` |

## 3. "摒弃以往要求"的实际影响（需要你点头的清单）

你说可以摒弃，但有几条是你过去**明确下过令**的，落地前我要你确认放弃，否则改完你又会觉得"没按我说的做"：

| 旧约束（你的原令） | 三个方向里的处理 | 需你确认 |
|---|---|---|
| **UI/正文一律思源黑体**（2026-09-21 全局约定） | A 改**衬线**（报纸感）、B 改**等宽为主**、C 保留无衬线但换超粗字重 | ❓ 要放弃吗 |
| **框线纪律**：`border-color` 恒吃 `ink-edge`，语义色只走 inset 阴影/底色 | C 直接用 3px 纯黑硬边（把边框当结构）、A 用朱红/双线作分隔 | ❓ 要放开吗 |
| **三档质感 pixel / linear / glass**（含毛玻璃与壁纸衬底实时透明） | A 无质感可言（纸）、B 无（实色+发光）、C 无（硬边）——即**三档质感体系会被取代** | ❓ 要废除还是并存 |
| **顶栏纯中文文字钮、图标去掉** | 三个方向都保留中文文字钮（这条我建议**不放弃**，它跟视觉方向无关） | ✅ 保留 |
| **一级轨八项 / 中文短标签** | 三个方向都保留（结构不变） | ✅ 保留 |
| **对比度 ≥4.5:1、no-magic、框线扫描三门禁** | 建议**不放弃**（可访问性与工程纪律，与"大胆"不冲突） | ✅ 保留 |

## 4. 落地成本（照实说）

| 方案 | 改动面 | 估工 | 风险 |
|---|---|---|---|
| **只换 token**（换色/字/圆角/影子变量，结构不动） | `DESIGN.md` + `build-tokens` + `tokens.css`/`themes.css`/`looks.css` | 小（半天内） | 最低；能立刻看到一个"完全不同的 Septcats" |
| **token + 组件 CSS 重写**（顶栏/侧栏/卡片/看板/日历的形态按方向重画） | 上述 + 约 30 个组件 CSS | 中（数天） | 中；`no-magic`/框线/对比度门禁要逐条过 |
| **结构级改造**（B 的遥测栏、A 的边注栏、C 的积木分区） | 组件 TSX + 状态 + i18n | 大 | 高；会牵到功能 |

**我的建议**：先按**方向 C 或 B** 做「token + 组件 CSS」这一步（不动结构），在真实应用里看一版；A 更适合作为"写作模式"的主题而不是全局——它的衬线正文在数据页会显得慢。

**推荐 C 的理由**：这一版最"大胆"、辨识度最高、信息密度最好，而且它天然与本次刚修的键盘可达路径同构（卡片自带「移到」硬按钮）；B 第二（对长时间使用最舒服）；A 保留做"写作模式"。

## 5. 需要你决策的三件事

1. **选一个方向**（A/B/C），或说"两两混合"（例如 B 的读数顶栏 + C 的硬边卡片）。
2. **确认放弃哪些旧约束**（见 §3 表格里三个 ❓：字体统一 / 框线纪律 / 三档质感体系）。
3. **先做哪一步**：只换 token（马上能看到）／token + 组件 CSS（数天）／要不要动结构。
