> **版本 0.3.0**

> **改进**
> - 编辑器内容真正落库（关掉重开仍在）；侧栏真实页面树；回收站可完整操作（恢复 / 彻底删除）

## 4. 老板冒烟（装包后 8 步）

1. 覆盖安装 → 打开：侧栏是你的真实页面树，**顶栏下方出现页签条**（重开应用后仍是上次打开的那几个页）
2. 新建页 → 输入中文 → **关掉应用重开** → 内容仍在
3. 打开几个页 → `Ctrl+1..9` 秒切 → 拖动页签排序 → 关掉一个页签（**页面本身没被删**）
4. 点顶栏 **AI**（或 `Ctrl+J`）→ 右侧面板开 → 发一句「本页第一段写了什么？带出处」→ 回复里的「页名 › 块N」**点一下能跳到那段** → 收起面板
5. 页面「⋯」→ **转为 Wiki**（侧栏出现 Wiki 分区、落地页有子页索引）→ 再**转回普通页**；再试 **转为多维数据** → 加几个不同类型的字段并填值 → 重启后值都在
6. 编辑区「⋯」→ **全宽**开关（每页独立）；`Ctrl+K` 搜 2 字中文（如「审计」）→ 命中可跳转
7. 新建一个页 → 输入 `[[` → 选另一个页完成**双链** → 打开那页看**反向链接**面板是否列出本页 → 点片段跳到源块
8. 设置 → **布局**：切三个预设看效果；再切语言到 English（界面全英文）→ 切回中文

## 5. 回滚方案

- 应用回滚：安装回 0.2.0 安装包；**回滚前备份数据根**（rc 期间写入的新版内容在 0.2.0 中读不到，旧内容不受影响）
- 发布回滚：`gh release edit latest` 指回上一版资产（feed 的 `latest.yml` 决定更新目标）
- 数据回滚：本版**不修改既有段文件**（只追加新段），故备份即可回退；`git worktree remove` 清理构建 worktree
