## 3. 发布说明（中英双版草稿）

### 中文

> **版本 0.3.0**
> 这一版把 Septcats 从「能记笔记」推到「能一起记笔记、能按模板开新篇」。
> **新增**
> - **协作编辑**：同一网盘文件夹下多设备同时编辑同一页，逐字符收敛不丢字（Yjs + 操作日志；真机双实例验收通过）
> - **模板**：任意页面「另存为模板」，从模板新建；**数据库模板**一并支持（属性与视图结构，不带数据行）。入口两处：侧栏「新建页面 ▾」与命令面板（Ctrl+K）的「模板」分组；设置页可管理（重命名 / 删除）
> - **界面语言**：简体中文 / English（设置 → 外观 → 语言；默认跟随系统）
> **改进**
> - 编辑器内容**真正落库**（关掉应用再打开，内容仍在）
> - 侧栏真实页面树：新建、双击重命名、折叠、收藏、最近、回收站
> - 回收站可完整操作：删除（面板命令或侧栏「⋯」）→ 恢复 / 彻底删除（二次确认）
> - 搜索：1–2 字中文也能命中；命中可直接跳转；顶栏面包屑显示真实层级
> - 空库显示空态（不再出现示例内容）；操作反馈（保存模板/移入回收站等）可见
> - 提示与状态文案全部本地化，深/浅主题对比度达标
> **升级提示**
> - 数据格式升级到 v3：**从 0.1.4 直升的用户请先升到 0.2.0 再升 0.3.0**；多设备同步请保证两端版本一致
> - 回退旧版前请先备份数据根目录

### English

> **Version 0.3.0**
> This release moves Septcats from "you can take notes" to "you can take notes together, and start from templates".
> **New**
> - **Collaborative editing**: multiple devices editing the same page converge character-by-character without losing text (Yjs + op-log; verified on two real instances)
> - **Templates**: "Save as template" from any page and create pages from templates; **database templates** included (properties and views structure, no data rows). Two entry points: sidebar "New Page ▾" and the "Templates" group in the command palette (Ctrl+K); manage them in Settings (rename / delete)
> - **UI language**: Simplified Chinese / English (Settings → Appearance → Language; follows the system by default)
> **Improved**
> - Editor content is now **truly persisted** (close the app, reopen — your text is there)
> - A real page tree: create, double-click to rename, collapse, favorites, recent, trash
> - A fully operable trash: delete (palette command or the row "⋯" menu) → restore / delete permanently (with confirmation)
> - Search: 1–2 character Chinese queries now match; results jump straight to the page; the top bar breadcrumb shows the real page hierarchy
> - Empty state for an empty library (no more sample content); visible feedback for actions (template saved, moved to trash, …)
> - All status/toast copy localized; contrast meets the target in both light and dark themes
> **Upgrade notes**
> - Data format is now v3: **users on 0.1.4 should upgrade to 0.2.0 first, then 0.3.0**; when syncing across devices keep both on the same version
> - Back up your data root before downgrading

## 4. 老板冒烟（装包后 6 步）

1. 覆盖安装 → 打开，侧栏应有你自己的页面树
2. 新建页 → 输入一段中文 → **关掉应用重开** → 内容仍在
3. Ctrl+K 搜 2 字中文（如「审计」）→ 命中并可跳转
4. 页面「⋯」→ 另存为模板 → 侧栏「新建页面 ▾」出现该模板 → 从模板建页
5. 删一个页 → 回收站 → 恢复；再删 → 彻底删除（应弹二次确认）
6. 设置 → 外观 → 语言切 English → 界面全英文 → 切回中文

## 5. 回滚方案

- 应用回滚：安装回 0.2.0 安装包；**回滚前备份数据根**（rc 期间写入的 v3 内容在 0.2.0 中读不到，旧 v1/v2 内容不受影响）
- 发布回滚：`gh release edit latest` 指回上一版资产（feed 的 `latest.yml` 决定更新目标）
- 数据回滚：本版**不修改既有段文件**（只追加 v3 段），故备份即可回退；`git worktree remove` 清理构建 worktree
