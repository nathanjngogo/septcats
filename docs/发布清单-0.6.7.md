## 一、老板反馈与根因

「毛玻璃效果不好，做不到背景通透。请优化。」

量化诊断（dev 靶逐像素，工具=gtrans.mjs 方差/彩度探针）：
- 旧玻璃的「环境光底」**只有灰度光斑**（accent/ink-edge 都是中性灰）→
  顶栏磨出来的彩度 chroma=0.6 ≈ 纯色板，「磨了像没磨」。
- chrome 面板 canvas 混色 42% 过浓 + 主区 86% 不透 → 通透感双重压制。

## 二、治本（looks.css glass 块）

| 维度 | 旧 | 新 | 依据 |
| :-- | :-- | :-- | :-- |
| 环境光斑 | 4 枚灰度 | +danger 22%/success 26%/selection 20% 三枚彩光 | chroma 0.6→**8.5** |
| chrome 混色 | canvas 42% | canvas **14%**（几乎只剩模糊本身） | 通透主诉求 |
| chrome 磨砂 | blur26 sat1.9 | blur**30** sat**2.6** | 彩光可见度 |
| 主区 | content 86% | content **58%** | 底光透出=通透主战场 |
| 浮层 | 66% blur24 | 60% blur28 sat2.2 | 一致性 |

三档像素差复测（门槛 8%）：pixel↔linear 28.19%、pixel↔glass **25.00%**、linear↔glass **22.10%**。

**防回退锚（L5 升级）**：彩光斑必在 + chrome canvas 占比 ≤30% + saturate ≥2.2 —
任何人回退成实心/灰光斑，ui 测试即红。正文可读性铁律保留（主区仍 58% 实心底，
编辑器内页不透视）。
