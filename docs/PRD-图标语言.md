# PRD · 图标语言（像素风退役 → 线族接管）

> 立项：老板 2026-10-06（QQ 频道同批令两条）
> 状态：R68 已落（导轨）｜R69 在途（全量换装）

## 1. 背景与决议
老板 10-06 先指着一级导航轨（截图红框）说「全部改为线条图标，设计要简约」，随后追加
「**取消像素风吧，不适合这个软件。**」——判据是**产品调性**：Septcats 是本地优先的类 Notion
笔记应用，像素硬边 glyph 与「极简 / 夜航仪表 / 毛玻璃」三条现存质感档不在同一语言里。

**决议**：图标语言由**像素族**改为**线族**（24 网格、`stroke=currentColor`、1.5、圆头圆角、零填充）。
像素族**不删除**，退役为「旧观感基线」（与下线质感档同法：文件与层测保留、应用零消费）。

## 4. 不变量（换装期间不得破）
1. 唯一出口仍是 `@septcats/ui` 的 `Icon`；业务代码禁直接 import 图标库。
2. `icon={X}` 的**名字语义不变**（换的是族，不是调用点结构）；`Icon` 的 `size` 档仍 16/20/24。
3. 装饰性/语义性无障碍口径不变（有 label → `role=img`；无 label → 装饰性 `aria-hidden`）。
4. 组件 CSS 零字面 hex、框线一律 `var(--sc-border-edge)`、no-magic 与对比度门禁全绿。
5. 像素族文件与其层测**保持可跑**（作基线对照），不做破坏性删除——删除需老板二次确认。

## 5. 待确认（不阻塞推进，按默认值执行）
1. 线族是否允许**双色/实心强调**（如 AI 机器人的"眼亮/眼灭"两态）？默认：单色描边，两态用 opacity 档。
2. 像素族 PNG 资产（112 张）是否随发版继续入盘？默认：保留在仓库、不再进包。
