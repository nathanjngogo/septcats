## 请你验的 7 步（编号）

1. **质感风格入口**：打开主题画廊 → 底部「**质感风格**」行 → 点 **Linear 极简** → 顶栏分割线应即时变细、按钮出现圆角、弹层换成柔影（不再像素风硬边）。
2. **毛玻璃**：同排点 **毛玻璃** → 画廊/侧栏应透出背景磨砂（backdrop blur + 饱和度）。
3. **持久化**：完全退出并重开（或命令面板里的重启）→ 质感应保持上次选择。
4. **命令面板**：`Ctrl+K` → 输入「质感」→ 应有三条精确切换命令。
5. **三轴正交**：质感 × 明暗（浅/深）× 配色 任意组合，互不覆盖、不串味。
6. **同步向导**：设置 → 数据与隐私 → 同步路径「更改…」→ 选网盘客户端同步目录 → 风险确认 → 一键重启生效；托盘状态行应显示同步态。
7. **附件真的会跟过去**：A 机在某页插入一张图片 → 托盘显示「待传 N」→ 网盘同步目录出现 `files/<hash>.enc` → B 机（可用下面 mac 包）拉到该页图片可正常显示；A 机加大附件时 CPU 不应明显起飞。
