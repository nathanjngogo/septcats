# PRD · 一级侧边栏（NavRail）

> 立项：老板 2026-09-29 令 —— 「请在左侧边栏再加一级侧边栏，用来区分笔记、知识库等一级菜单。」
> 状态：定稿（默认值已选定，仅 1 条口径待老板一句话确认，见 §5）
> 里程碑：R48 / TASK-T93-01

## 1. 目标

在现有左侧栏（240px 页面树）**左边**再加一列**一级导航轨（rail，56px）**，把「一级菜单」显性化：
一级 = 你去哪块地（笔记 / 知识库 / 工作台 / 模板 / 回收站），二级 = 那块地里的内容（页面树 / 库列表…）。

## 2. 范围

### 2.1 一级轨（NavRail，56px，全高，位于最左）
- **纯中文短标签**（2 字），不挂图标 —— 延续老板 09-29「顶栏按键全中文 → 图标去掉」的同一口味；
- 五项：**笔记 / 知识库 / 工作台 / 模板 / 回收站**；
- 当前项高亮（`aria-current="page"` + 弱底 + ink 字，三轴随主题）；hover 像素立体反馈；
- 与现有「侧栏折叠」正交：折叠时只收二级栏，一级轨**保留**（一级导航不该被折叠掉）；
- 键盘可达（Tab 序在页面树之前）；窄窗（760）不挤压主区可读宽度（56px 固定）。

### 2.2 二级栏分流规则
| 一级项 | 二级栏内容 | 主区 |
|---|---|---|
| 笔记 | 页面树（现状全量：新建 / 收藏 / 最近 / Wiki / 模板 / 树） | 编辑器（现状） |
| 知识库 | **库列表 + 「新建库…」**（本机全部库，当前库打勾；点条目即切库） | 编辑器（切换后的库） |
| 工作台 | 页面树（保持可用） | 工作台仪表盘（现状 openHome） |
| 模板 | 页面树（保持可用） | 模板市场（现状 openWorkbenchMarket） |
| 回收站 | 页面树（保持可用） | 回收站列表（现状enterTrash） |

### 2.3 布局（零回归口径）
- `AppShell` 新增**可选** `rail` 插槽 → `.sc-shell--rail` 修饰类；**不传 rail 时网格/几何逐像素不变**（现有 T52/T57/T59 几何契约全部保活）；
- 有 rail 时：`.sc-shell__body` 三列 = `rail(56) | sidebar(240) | 1fr`；顶栏与主区右移一列；rail 与侧栏同跨两行（通高到窗口内容区顶）；
- 折叠态：`rail(56) | 1fr`（二级栏隐藏，一级轨保留）。

## 3. 取舍（默认值）

1. **不动数据模型**：一级「知识库」的内容 = 本机**库列表**（`workspaces.list` 既有通道）+ 新建库入口。
   理由：仓内「库(workspace)」分三型（工作台库/知识库库/空白库），但**库类型当前未持久化**
   （`createWorkspaceWithType` 只按类型在 renderer 侧播种，`workspaces.create` 只收 name）——
   要按类型过滤「知识库」需加一次 schema 迁移 + 通道扩参，属数据模型变更 → 先不动，留 §5 问老板。
2. 一级轨不做图标：与老板最近的图标口径一致；若他要求加图标，改一个组件即可。
3. 一级/二级宽度都固定，不做拖拽调宽（现有侧栏拖拽把手只调二级，保持不变）。
