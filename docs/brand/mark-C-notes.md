# Mark C · 猫脸徽章（极简派）设计说明

- **构图逻辑**：以 r=42 正圆（cx=64, cy=66）为脸轮廓，徽章式强几何；两耳三角开口端落在圆上、借圆作底边，耳内不加线，耳尖由 round linejoin 自然倒圆；眼为两条向下闭眼弧（宽 10 高 4），鼻小三角居中 y≈68，胡须左右各两条、与圆留 6px 间隙；下方领口弧线托住 #A16207 实心铃铛（弧中点，r≈4），彩色仅此一色。
- **16px 缩放预期**：1.5px 描边下脸圆+双耳剪影仍清晰，铃铛琥珀点可辨；但 6px 间隙的胡须短线（约 1px 可见）会糊掉或消失——属可接受退化，不破坏识别。
- **favicon 变体建议**：另存去胡须版本（删 4 条 h9 短线），必要时同时去鼻，只留脸、耳、眼、铃铛，16px 下最干净。
- **与 A/B 定位差异**：A（坐姿全形）用于品牌主视觉/插画场景，B（一笔盘猫）用于强调灵巧感的图形化场合；C 是纯徽章，专用于 favicon、系统托盘、工具栏等超小尺寸 UI。
