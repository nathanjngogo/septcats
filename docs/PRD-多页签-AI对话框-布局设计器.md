# PRD：多页签编辑区 · AI 对话框 · 布局设计器（老板新需求）

> PM：Hermes ｜ 日期：2026-09-19 ｜ 状态：**方案待老板一句话确认**（不确认我按推荐值推进）
> 背景：老板三条新需求（原文）「1. 编辑区需要能分页显示，能够快速切换页面 2. AI部分应该要有对话框 3. 我希望能够学习Hermes的设计，有个布局设计器」

## A. 编辑区多页签（「分页显示 + 快速切换页面」）

**方案（推荐）**：编辑区顶部（顶栏下方）加**标签条**：
- 打开页面 → 生成/复用标签；**同一页不重复开**（侧栏点击/搜索跳转/模板建页都走同一入口）
- 点击切换 · `×` 关闭 · 中键关闭 · 拖拽排序 · 溢出时横向滚动
- 快捷键：`Ctrl+W` 关当前、`Ctrl+Tab` 下一个、`Ctrl+1..9` 跳第 N 个
- **持久化**：标签集合 + 当前选中项存本地（userData 的 UI 状态文件，**不进账本**——它不是内容数据）；重开应用恢复
- 关闭当前标签 → 回落到**相邻**标签；无标签 → 空态
- 不做：多窗口、分屏对照（后续如需再议）

**验收**：开 5 页签→乱序切换→重开仍在且选中项正确；同页不重复；关闭回落到相邻；双主题四态；`no-magic`/`build-tokens` 通过。

**成本**：~2–3 人日（纯 renderer + 本地 UI 状态）

## B. AI 对话框（「AI 部分应该要有对话框」）

**方案（推荐）**：**右侧可收起面板**（与布局设计器联动，可换成底部抽屉）：
- **多轮对话**：历史消息列表 + 输入框；上下文 = 当前页（可选「附带选中块」）
- 引用当前页内容时**带出处**（页名 + 块位置），便于回溯
- **历史持久化**（本地存储；**隐私硬不变量照旧**：云端默认关；非本地端点无 consent 时 fetch 零调用；密钥只进 CredentialStore，不进日志/同步包）
- 入口：顶栏 AI 按钮 + 命令面板命令 + 快捷键（如 `Ctrl+J`）
- 与既有「动作式 AI」（选区摘要/属性列）并存：动作=一次性，对话框=多轮
- 流式输出（本地 LM Studio 支持）与错误可读提示复用既有 AI 面板口径

**验收**：多轮上下文可续（第 3 轮能引用第 1 轮的结论）；引用当前页内容正确；历史重开仍在；**无 consent 时对非本地端点零外呼**（真机断言）；深/浅主题；键盘可达。

**成本**：~3–4 人日（renderer 面板 + 上下文装配 + 历史存储；复用既有 AI 通道）

## C. 布局设计器（「学习 Hermes 的设计」）

**方案（推荐，克制）**：**预设 + 参数调节**，不做任意拖拽窗口：
- **预设**：「Notion 风（侧栏左 + 内容居中）」/「宽屏专注（无侧栏 + 大 measure）」/「工作台（侧栏 + 右侧 AI 面板）」
- **可调参数**：侧栏位置（左/收起）· 侧栏宽度 · 内容最大宽度（measure）· AI 面板位置（右/底/隐藏）· 标签条显隐 · 主题（浅/深/跟随）· 密度（紧凑/舒适）
- 布局以 **JSON 存本地**（userData），支持**导出/导入**（便于分享你的偏好）
- 学习 Hermes 的点：Hermes 桌面是「多面板 + 布局预设（apply_layout）」的思路——我们**照「预设 + 参数」**做，而非自由漂浮窗口（可维护、可回归、不破 UI 红线）

**验收**：切预设即时生效；各项调整持久化、重开保持；**不破坏既有红线**（窗口零滚动、侧栏可完全收起、块手柄装订线、对比度门禁）；导出 JSON 再导入等价。

**成本**：~3–4 人日（依赖 A/B 先落地——布局设计器要能配置它们）
