# 交付说明 0.6.5 —— 原生标题栏/菜单栏随主题变色

**产物**：`apps/desktop/dist/Septcats Setup 0.6.5.exe`（103,537,227 B）
**sha256**：`f0051b01564cc82d4d236c47eb80ce282f86d6a38db2e815163017633c366d63`
直接覆盖安装即可（DB 无变更）。

## 你圈的到底是什么
截图那条 = **Windows 原生标题栏**（Septcats + 最小化/最大化/关闭）**+ 原生菜单栏**
（文件/编辑/视图/帮助）。这两块由系统和 Electron 主进程绘制，不归界面 CSS 管——
所以旧版切「深色」时它们一直顶着一带浅灰，跟内容区脱节。

## 这版怎么治
「设置→外观→主题（明暗）」现在直接驱动系统层：
- **深色** → 标题栏/菜单栏变深色、按钮文字变白，窗口预绘底色同步 #141414（启动不再白闪）；
- **浅色** → 恢复浅带；
- **跟随系统** → 跟 Windows 深浅色设置走。
配色派系与质感风格仍是界面层概念，不强行往原生条上套（原生条没有玻璃/网格，硬套=假效果）。

## 验收步骤
1. 覆盖安装 0.6.5 → 打开设置 → 外观 → 主题点「深色」：**标题栏和菜单栏当场变深**（不用再开任何窗口）。
2. 点「跟随系统」→ 到 Windows 设置里切深浅色，应用条带应跟着变。
3. 重启应用，上一步选的主题保持（含标题栏带）。
