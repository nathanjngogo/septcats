## 一、本轮改动（还债冲刺：R29 缺陷账最后挂账项 H-06）

**缺陷**：`page_link_index`（双链派生索引）与 `mention`（schema.v2 预留反链表）不在
`REBUILD_CLEAR_SQL` 清表清单里 → 段重建（merge/replace 两种模式）与便携导入后，
派生索引可能与投影不一致：回链面板挂着指向已消失页的旧行、漏掉新行。

**治本**（三层）：
| 落点 | 文件 |
| :-- | :-- |
| 同步重建内核（解析口径与启动重建完全同源；白名单语句） | `db/linkRebuild.ts`（新） |
| `rebuildFromSegments` 事务尾部调用（FTS 同事务、同回滚语义） | `db/server.ts` |
| `REBUILD_CLEAR_SQL` 补 `page_link_index` + `mention` 两条清表 | `db/server.ts` |

两条消费链（同步 runtime merge、便携导入 replace）都经同一 core 派发 → 自动受益，
无需分别接线。`mention` 查实为**零读写预留表**（无任何维护方）——清表语句一并补上，
防未来回填后再漂移。
