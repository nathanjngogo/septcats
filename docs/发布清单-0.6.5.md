## 一、本轮改动（老板截图圈定：「我需要连图片中的部分一并改变主题」）

圈定物 = **Windows 原生标题栏（Septcats + 最小化/最大化/关闭）+ 原生菜单栏（文件/编辑/视图/帮助）**。
这两块不归 CSS 管（OS/Electron 主进程绘制），旧版「主题（明暗）」只换 renderer → 原生条纹丝不动。

| 落点 | 文件 |
| :-- | :-- |
| 映射纯函数（ThemeMode→ChromeTheme + 画布背景色，与 tokens.css 同源） | `src/main/windowChromeTheme.ts`（新） |
| 接线：`nativeTheme.themeSource` + 已存窗 `setBackgroundColor` + 启动/patch 两路 + **须先于 createWindow** | `src/main/index.ts`（6 处） |
| 常驻自证日志（`chromeTheme applied/probe/windowState`，main→renderer executeJavaScript） | `src/main/index.ts` |

口径：只联动**明暗两态**（dark=#141414 / light=#F5F5F5=canvas token）；palette/look 是
renderer 的 CSS 概念，原生条无玻璃/网格可言，不强行联动。
