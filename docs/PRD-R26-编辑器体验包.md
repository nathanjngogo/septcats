# PRD-R26 · 编辑器体验细节包

> 立项：PM（Hermes）09-24 · 基线 main `060bb03`（R25 收口后）· 授权：老板「继续跑」
> 两单串行：T77（块属性 UI 补齐，先行）→ T78（跨块多选，依赖 T77 的菜单基建）。

## 0. 侦察结论（现状=代码事实，09-24 grep 实证）

| 面 | 已有 | 缺口 |
|---|---|---|
| 代码块 | `blocks.ts` 投影 attrs `lang`/`wrap`；model.ts 有 codeBlock 映射；markdown 粘贴可带语言 | **无任何 UI** 能改 lang/wrap——用户打了代码块只能永远是纯文本高亮 |
| 图片块 | `image` 投影 attrs `width`/`caption`/`file_id` | 无缩放交互，width 恒默认 |
| 块手柄 | ⋮⋮：删除/复制/转为 13 型/颜色/单块拖拽（T60 dragHandleProps） | 仅作用**当前单块**；跨块批量（选 5 块一起删/移动）无路径 |

共同特征：**前两项=「真相层 attr 已存在、纯 UI 缺失」**——op-log/同步/导入导出零改动，风险极低；第三项才碰交互模型，故拆两单。

## 1. T77 · 代码块与图片体验（先行）

- **A 代码块语言栏**：聚焦代码块时右上角浮出语言选择（commonMark 12 语言白名单 + 自动/纯文本；下拉复用既有 Menu token 体系）+ 换行开关钮（wrap）。选择结果写块 attr（lang/wrap），投影→op 走既有 patch 通道。
- **B 语言可见性**：非聚焦时代码块左上角淡显 lang 标签（`--faint` token），让用户知道当前高亮语言。
- **C 图片宽度拖拽**：图片右缘拖拽柄（pointer events，同 T60 把手口径），宽度写 `width` attr（25%~100% 吸附档位或像素，CB 按既有 attr 语义定并记 §0）；caption 已有则不动。
- 斜杠「代码块」插入时语言默认空（自动），保持现状。

## 2. T78 · 跨块多选与批量操作（T77 收口后派）

- **选择模型**：Shift+click ⋮⋮ 手柄 = 从锚块扩选到该块（连续区间）；手柄菜单加「选中 N 块」态提示；Esc/点正文清选。
- **批量动作**：多选态下菜单项切换为 批量删除 / 批量复制 / 批量转为（13 型）/ 拖拽=整组移动（复用 dnd 通道，落位后按原相对序）。
- **op 口径**：批量=发多个单块 op（同事务批提交），**不新增 op 类型**——op-log v3 与同步零改动是红线。
- undo 口径：一次批量=可一次撤销（复用既有撤销链；若撤销粒度天然为单 op，接受并在 §0 记口径）。

## 3. 红线（全量继承）
§16 + R14（浮层/标签/拖拽柄全吃 `var(--sc-*)`，禁灰线裸 px）；no-magic；不建表不加 npm 依赖（下拉/菜单用既有组件）；op-log targetTable 与 op 类型零新增；启动零外联；禁省略号占位；i18n zh/en 成对；testid 契约随施工单。

## 4. 验收
四门禁只增不减（基线 desktop 1094 / ui 168 / tsc 0 / no-magic）；单测覆盖 attr 写入往返 + 多选区间计算纯函数 + 批量 op 序列；PM 真机探针 T77（选语言→高亮→重启还原；图片拖宽→还原）+ T78（扩选→批量删→撤销→重启）；编辑器回归电池（T60/61/59）+ 邻近（T76 新块）零回归。

## 5. 显性不做（记档）
行号显示、代码块语法高亮引擎更换（现无高亮=本包也不引 highlight.js，纯 attr）、多选非连续 ctrl+click（一期只做区间）、图片裁剪/滤镜、块级批注评论。
