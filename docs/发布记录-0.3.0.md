## 发布过程中遇到并解决的两个阻塞（如实记录）

1. **`SEPTCATS_FEED_KEY` 未在环境中**（脚本报「需要 feed 私钥（离线备份在 E:\密钥备份\septcats-feed-keys）」）→ 解：**只把私钥文件路径**注入环境变量（脚本自身 `readFileSync` 读取），**密钥内容未进入对话、未落盘到仓库、未出现在日志**。
2. **干净 worktree 缺公钥 `apps/desktop/tmp/feed-keys/septcats-feed.pub`**（`tmp/` 不入库）→ 解：从离线备份复制公钥（公钥非秘密）→ 验签通过。
