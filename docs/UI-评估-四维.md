## 1. 配色（Color）

### 现状实测
- 平面五级：`canvas / content / surface / surface-raised / surface-active`（灰阶，chrome=canvas、正文区=content）。
- 文字三档 + 装饰：`ink / ink-secondary / ink-faint`（12px 小字下限阈 AA）+ `icon-faint`。
- 强调色：`accent` = **灰阶**（浅 `#333333` / 深 `#D4D4D4`）——只做「实心强调底」（主按钮、勾选、开关 on）；T53-01 起琥珀退役。
- 语义色**两粒**：`danger`（删除/冲突/同步失败）、`success`（同步中/完成）。
- 立体三色源：`bevel-hi / bevel-lo / shadow-pixel`；结构线独立色源 `ink-edge`（与 ink 同值不同义）。
- 门禁实测：`contrast.test` 阈值 **4.5**，覆盖「ink 三档 × 三级平面」+「on-accent vs accent」+「状态色 vs canvas」，**双主题全过**；另 `pixel-icon-contrast` 按 token × 实际平面逐对算、两主题打印实测值。

### Apple 准则对照
| 准则 | 本仓现状 | 判定 |
|---|---|---|
| 色彩克制、语汇小（§16.6 简洁、§12 色只上实心层） | 5 平面 + 3 字档 + 1 灰阶强调 + **仅 2 粒语义色**；强调色只落实心底 | ✅ |
| 文字在变化背景上保可读（§12 vibrancy） | 壁纸亮度 × 主题亮度冲突时挂 `data-wallpaper-clash` 自适应加纱（chrome 14→72% / 正文 58→90%），保深字对比 | 🟡 只按**亮度**一维；色相冲突（暖壁纸×冷主题）未处理 |
| 明暗自适应（§16.7 craft） | 双主题 token 同源生成（`[data-theme=dark]` 由构建脚本产出），非手改 | ✅ |
| 高对比诉求（§14） | **本批补齐** `prefers-contrast: more`：面近实心 + 框线升实心 2px `ink-edge`（门禁测试钉死） | ✅（本批） |

**待办（P1）**：vibrancy 从「只比亮度」升级为「亮度 + 色相/彩度」双判；玻璃档 chrome 上的次级文字给「提亮一档 + 微字距」的振动处理，而不是等比灰。

## 2. 质感（Material）

### 现状实测（三档质感，`looks.css` + T85-02 实测）
| 档 | 半径 | 框线 | 磨砂/底 | 实测 |
|---|---|---|---|---|
| pixel（像素） | 0 | 2px 实心 `ink-edge` | 实心 + bevel/`pixel-out` | 质感探针 22 项过 |
| linear（线性） | 4/6/10/14 | 1px `ink-edge` 38% | 弱环境光渐变，面实心 | — |
| glass（毛玻璃） | 8/10/14/20 | 1px `ink-edge` 26% | chrome `canvas 14%` + `blur(30px) saturate(2.6)`；主区 `content 58%`；浮层 `surface-raised 60%` + `blur(28px) saturate(2.2)`；壁纸衬底（屏幕映射实时视差）+ 冲突自适应纱 | pixel↔glass **25.0%**、linear↔glass **22.1%**（门 ≥8%） |

### Apple 准则对照
| 准则（§12/§14） | 本仓现状 | 判定 |
|---|---|---|
| 材质权重编码层级（大而轻→小而重） | chrome 14%（最大最轻）→ 主区 58% → 浮层 60%（最重）；**方向正确** | ✅ |
| 更大面应更「厚」 | chrome `blur 30` > 浮层 `blur 28` | ✅ |
| 禁「薄透明叠薄透明」 | 浮层 60% 已近实心，叠在 chrome 上仍可读；冲突时加纱到 85%+ | ✅ |
| 滚动边缘渐隐而非硬分割线 | **缺**：靠硬接缝（老板红线「像素框线」）；滚动内容与浮动 chrome 交界无渐隐 | 🟡 P1 |
| 材质「成形」而非淡入 | look 切换瞬时生效（无 blur/scale 过渡） | 🟡 P2 |
| `prefers-reduced-motion` | 19 处组件级实现（含新组件） | ✅ |
| `prefers-contrast: more` | **本批补齐** | ✅（本批） |
| `prefers-reduced-transparency` | **决策：不自动降级**（见下） | ✅ 有据决策 |

### ⛔→✅ 本批实测抓到的关键坑（值得单列）
Windows 的「透明效果」开关会被 Chromium 映射成 `prefers-reduced-transparency: reduce`，**本机 `EnableTransparency=0`（老板机原值）⇒ 该信号默认命中**。
我第一版按 Apple 字面实现「去磨砂 + 面回实心」，真机立刻四红（T85：`blur=none`、chrome 回 `rgb(20,20,20)`、pixel↔glass 差 **7.65% < 8%** 门）——即：**用户显式选中的玻璃档会被系统化妆开关静默打回实心**。
**定稿口径**：材质选择权归**应用内 look 档**（pixel/linear 本就完全实心、一点即得；glass 是显式选择），系统级开关不得推翻它 —— Apple §16.2 Agency 优先于 §14 的机械照搬。若要支持，正解是设置页给「外观：跟随系统减少透明度」开关（默认关），不在 CSS 里静默改材质。已加**负向契约测试**防回退，决策记录写在 `looks.css`。

## 3. 图形（Graphics / Shapes）

### 现状实测
- **图标单族**：像素 glyph 28 枚（16/24px × 明暗两态 = 112 张 QC 产物 + 拼版总览），出口唯一（`@septcats/ui`），全仓 `icon={X}` 调用点全量收口、零混族（Sparkle/phosphor 零残留，门禁钉死）。
- **半径成套**：base 2/4/6/8 + glass 8/10/14/20 + pixel 0 —— 每档自成体系，不同档不混用。
- **同心半径**：玻璃面板 `radius 14` ↔ 行 `radius 10` ≈ 外半径 − 内衬（近似同心）✅。
- **命中区实测**（真机量）：顶栏文字钮 **28 高**、图标钮 **28×28**、一级轨条 **56×32**、侧栏/知识库行 **36**。
- **按压反馈覆盖**：`Button` / `IconButton` 有 `:active`；**一级轨条与知识库行原缺**（本批补）。

### Apple 准则对照
| 准则（§10/§16.7） | 本仓现状 | 判定 |
|---|---|---|
| 图标族一致、单出口 | 单族 + 出口唯一 + 逐格矩阵基线 | ✅ |
| 命中区 ≥ 触控 44 / 桌面 ~28–32 | 28–36，桌面指针场景可接受；**<32 的钮无隐形命中内衬** | 🟡 P1 |
| 按下即反馈（不等 release） | 本批补齐一级轨/知识库行；其余组件已有 | ✅（本批） |
| 形状语言与质感档一致 | pixel 直角、glass 大圆角、linear 中间档，各自成套 | ✅ |
| 装饰不承载语义 | 装饰格（glyph 内部 tone 档）只做明暗，不编码状态 | ✅ |

**待办（P1）**：给 28px 级钮加 4px 隐形命中内衬（`::before` 扩展热区，不占盒模型、不改观感）。

## 4. 线条（Lines / Strokes）与排版节奏

### 现状实测
- **唯一色源** `ink-edge`：外框（面板/卡片/输入/按钮/浮层/弹窗/标签/键帽/开关轨）一律 **2px 实心**；表格网格、列表分隔 **1px**。
- **相邻边只画一次**：5 条接缝归属表（顶栏↔主区、侧栏↔主区、标签条↔正文、编辑列↔AI 面板 ×2），侧栏接缝用 `::after` 定位条避免压窄内层 2px。
- **浮层族统一** 2px；focus 恒黑线 + 全局 2px `focus-ring`（禁彩色 focus）；虚线/点线保留线型只升颜色。
- **质感档浓淡谱**：pixel 2px 实心 → linear 1px 38% → glass 1px 26%（同一语言换浓度，不是换语言）✅。
- 门禁实测：`pixel-borders` 扫描 4 源目录 **213 条 border 声明，ink-edge 命中 170，白名单放行 43，越界 0**。
- **字距体系**：`h1 -0.01em / h2 -0.005em / body +0.01em`；本批补 **h3 -0.002em** 并**修掉 2 处把 spacing token(`2px`) 当字距**的误用（PageLock 两处 → `0.02em`）。
- 行高随字号反向：28→1.3 / 22→1.35 / 18→1.4 / 16→1.75 / 12–14→1.5 ✅。

### Apple 准则对照
| 准则（§12/§15） | 本仓现状 | 判定 |
|---|---|---|
| 框线语义唯一、浓淡随材质 | 单色源 + 三档浓淡 | ✅ |
| 硬分割线 vs 滚动边缘渐隐 | 硬接缝（老板红线）；渐隐缺失 | 🟡 P1（补充而非替换） |
| 字距随字号（大负小正） | h1/h2/h3 ✅、正文 ✅；**UI 12–14px 无 token 级字距**，组件里 3 处 `0.2px` + 1 处 `0.5px` 为 ad-hoc | 🟡 P2 |
| 行高随字号反向 | 单调正确 | ✅ |
| 米字/中文排印规则（中西文间隙、行首禁则、行长上限） | 规则已写进 DESIGN.md 并在编辑器强制 | ✅ |
| Dynamic Type（随用户字号缩放） | 全仓 px 固定，未 rem 化 | ⛔ P2（大改，需单独立项） |
