# PRD · Notion 对齐（老板 2026-10-07 令）

> 老板原话：「感觉总体界面跟Notion差了很多，我需要跟它一模一样。」

## 0. 先说清"一模一样"的边界（避免后面互相误解）
**能做成一样的**：信息架构（侧栏树/页面头部/块级交互）、版式度量（字号/行高/间距/内容列宽）、
视觉基调（几乎零描边、无立体阴影、hover 才显形的克制风）、交互细节（块左侧 ⋮⋮ 与 ＋、
行尾 ⋯、拖拽把手、选中态浅底）。
**做不到逐像素相同的**：① Notion 的**字体栈与私有图标/插画**（且本仓有一条老板自己的全局字规矩：
界面一律思源黑体自托管）；② Notion 自己的功能面（数据库公式/关系/同步块、评论、分享、团队空间）；
③ 我们是本地优先的应用，有些东西（同步药丸、本地库路径）Notion 没有。
**结论**：按「Notion 观感对齐」做，逐项给度量靶 + 对照截图；不宣称逐像素。

## 1. 现状 vs Notion（一眼可辨的几处主差）
| 面 | 我们现在（夜航仪表/像素/毛玻璃三档） | Notion | 处置 |
|---|---|---|---|
| 描边 | 2px 硬描边（`--sc-border-edge`）满场 | 几乎零描边，靠留白与浅底色分层 | 新增「Notion 风」：边框 0/1px 发丝、只用底色与 hover 分层 |
| 阴影 | 立体斜角 bevel + pixel-flat + 弹层硬影 | 极轻浮层影（0 1px 3px rgba(0,0,0,.1) 级） | 重定浮层影 token |
| 字体 | 思源黑体（老板全局规矩，自托管） | 系统 UI 栈（-apple-system/Segoe/Inter 类） | **待老板拍**（见 §3①） |
| 页面标题 | 与正文同族、偏小 | 40px/600、下方留白足 | 改版式度量 |
| 内容列宽 | 编辑器量测档（`--sc-space-editor-measure`） | 708px（Notion 正文列），全宽可切 | 对齐 708px |
| 侧栏行 | 28px 行高 + 中文钮 + 徽标 | 28px 行 + 24px/级缩进 + hover ⋯ + 圆角浅底 | 对齐行度量与 hover 语言 |
| 块交互 | ⋮⋮ 手柄 + 菜单 | 左侧 hover 出 ⋮⋮ 与 ＋，块高亮 | 对齐（我们已有手柄，需挪到 gutter 并补 ＋）|
| 顶栏 | 读数区 + 药丸 + 中文文字钮 | 面包屑 + 右侧 分享/评论/⋯ | 收敛顶栏（**同步药丸是本地应用必需**，保留但降噪） |

## 2. 分期（每期出对照截图，可回退）
- **N1 基调与版式（先做，收益最大）**：新增 look 档 `notion`（零描边/发丝线、极轻影、圆角 6px、
  hover 浅底）+ 字号体系对齐（标题 40/600、正文 16/1.5、代码 14）+ 内容列 708px。
  只动 token 与 look 层 ⇒ **不动组件几何、不动数据面**，风险最低。
- **N2 页面头部与正文**：页头 = 大标题 + 图标槽（**已按老板 10-07 令摘除装饰图标**）、
  面包屑移到顶栏左侧；块 gutter 的 ⋮⋮ / ＋ hover 显形；块选中高亮。
- **N3 侧栏与树**：行度量、缩进、hover ⋯ 菜单、拖拽排序把手、新建行语言。
- **N4 模块面**：多维表格/日历/待办/工作台 按 Notion 数据库与日历件的观感对齐（这一期最大，
  需要单独排期；部分交互（看板/表/画廊）我们已有，主要是外观与密度）。
- **N5 顶栏与设置**：顶栏收敛、设置页改用 Notion 式分组列表。

## 3. 待老板拍（会改变实现路径的三条）
1. **三档质感**：全部退役、统一成「Notion 风」，还是**保留三档 + 新增一档 Notion**（我的推荐：
   先加一档、验证后再决定退役——可回退，且不动既有测试口径）。
2. **字体**：本仓有一条你定的全局规矩「界面一律思源黑体（自托管，禁在线字体）」；Notion 用的是
   系统 UI 字体栈。要"更像"，是否允许：**界面字改用系统字体栈**（等于改那条全局规矩），
   还是**继续思源黑体、只对齐字号与行高**（我的推荐：先对齐度量，字体另议）。
3. **范围**：先只做「笔记页 + 侧栏 + 顶栏」（Notion 核心，1–2 期能看出效果），
   还是连多维表格/日历/待办一起排（工期显著更长）。
