## 2. 发布动作（两阶段灰度，推荐）

**阶段 A —— 归档 tag（不影响 0.1.x 用户的自动更新）**
1. 版本 bump：`apps/desktop/package.json` `0.1.4 → 0.2.0`（唯一落点）。
2. `pnpm -C apps/desktop dist`（出包）+ `pnpm -C apps/desktop dist:check`（feed 校验）。
3. 仅创建 `v0.2.0` 归档 release 并上传资产（**不上传 latest 通道**）：
   `gh release create v0.2.0 --repo <USER>/<REPO> --title "Septcats 0.2.0" --notes "<见 §3 发布说明>" dist/"Septcats Setup 0.2.0.exe" dist/"Septcats Setup 0.2.0.exe.blockmap" dist/latest.yml dist/latest.yml.sig`
4. 匿名拉取验证（带 curl 200 检查）：`.../releases/download/v0.2.0/Septcats.Setup.0.2.0.exe`。

**阶段 B —— 推广到 latest（用户侧自动更新通道，老板冒烟通过后执行）**
5. `gh release upload latest <四个资产> --clobber --repo <USER>/<REPO>`（`latest` 为既有 feed 通道 tag）。
6. 匿名验证：`latest.yml` + `latest.yml.sig` + 安装包均 HTTP 200；`.sig` 与内置公钥验签通过（应用内硬编码，篡改即 `E_FEED_SIGNATURE` 拒装）。
7. 更新器冒烟：在装了 0.1.4 的机器上手动检查更新 → 应提示 0.2.0 → 安装成功 → 版本显示 0.2.0。

> 若不想分阶段：直接 `bash apps/desktop/scripts/publish.sh`（幂等，同时推 `v0.2.0` + `latest`）。**注意**：一次性推送会让所有 0.1.x 客户端在下一次更新检查时直接拿到 0.2.0。

## 3. 发布说明草稿（0.2.0）

```
Septcats 0.2.0 —— AI 助手就绪（全部本地可跑，云端默认关闭）

新增
- AI 助手（设置 → AI 助手）：支持 LM Studio / Ollama / 任意 OpenAI 兼容端点，API 密钥只进系统凭据库

- AI 属性列：数据库里新增一种列，按你写的指令为该行生成内容（可单行生成，也可对当前视图前 20 行批量生成并确认）

- 云端服务默认关闭、需显式授权；未授权或有本地模型可用时不会发起任何外部请求
- 密钥不入配置文件、不入日志、不入同步包
修复
- 数据库记录标题「双击改名」不生效（根因：焦点被抢导致编辑框瞬时失焦）
```

## 4. 老板冒烟清单（编号步骤，PM 出）

1. 安装 `Septcats.Setup.0.2.0.exe`（覆盖 0.1.4 即可，数据在 `Roaming\Septcats`，不丢）。
2. 打开应用 → 左下角/关于处版本应显示 **0.2.0**。
3. 设置 → **AI 助手**：应显示「未启用」；打开启用开关 → 添加 provider（LM Studio，`http://127.0.0.1:1234`）→ 点「测试连接」应出「已连接，N 个模型」→ 选择模型。
4. 回到任一页面 → 选中一段文字 → 命令面板（Ctrl+K）输入「AI 摘要」→ 面板出结果 → 点「应用」→ 正文被替换。
5. 把某页「转为数据库」→ 新建记录 → 「新属性」选 **AI** → 列头「编辑生成指令」写一句指令 → 该行「AI 生成」→ 单元格出现内容。
6. 关掉 LM Studio → 再点「AI 生成」→ 应给出可读错误提示（不崩、不写脏值）。
7. 重启应用 → 页面与数据库内容仍在，AI 配置仍在，密钥不需要重新输入。
8. 若有第二台设备：同网盘文件夹双设备编辑 → 应无冲突红条（协作能力仍属 0.3.0 范围，本版本只需保证不回归）。

## 5. 回滚

- `latest` 通道可回退：把上一版（0.1.4）四个资产 `gh release upload latest ... --clobber` 覆盖回去即可（feed URL/tag 不变）。
- 更新器为 fail-closed：`latest.yml` 缺签或被篡改一律拒装，不会出现半升级状态。
