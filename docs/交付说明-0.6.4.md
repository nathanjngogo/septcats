## 为什么打回（根因，已量化）
旧版三档质感在正常主界面的**像素差实测只有 1.86~1.97%**（Linear vs 毛玻璃 = 0.14%）——
等于没变。根因：毛玻璃只把顶栏/侧栏做成 84% 半透明，但它们背后是**同色实心画布**，
磨了没东西可磨；Linear 只改了 1px 边线和 4px 圆角，幅度太小。

## 这版改了什么（三档现在一眼可辨）
- **像素**：4px 网格纸底 + 弹层 8px 硬位移投影 + 全 0 圆角（像素风招牌）
- **Linear 极简**：chrome 灰面（与正文白面分层）+ 发丝边框 + 圆角 4/6/10/14 + 分层柔影
- **毛玻璃**：外壳铺环境光渐变 + 顶栏/侧栏 42% 半透明真磨砂（blur 26px）+ 圆角 8/10/14/20 +
  浮层（命令面板/弹层）66% 重磨砂；正文保持 86% 实心（可读性铁律）

## 验收步骤
1. 设置 → 外观 → 质感风格，连按三档切换：**不用看说明也能一眼看出界面变了**
   （网格纸 / 灰面极简 / 磨砂玻璃）。
2. 毛玻璃下按 Ctrl+K：命令面板应明显磨砂、透出底下的内容。
3. 深色主题下重复第 1 步（磨砂用环境光，暗底同样成立）。
4. 三档下正文都保持清晰可读（毛玻璃只作用于 chrome 和浮层）。
