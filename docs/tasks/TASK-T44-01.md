# TASK-T44-01 · R8：双链（Obsidian 式 `[[ ]]` + 反向链接）

> PM：Hermes ｜ P2（老板新需求 R8）｜ 前置：T40-01（字段）与 T42-01（Wiki）之后排队
> 老板原文：「再补充一个功能，类似Obsidian的双链功能。」

## 0. 第一步：核实承载（**必须先给结论，别直接开写**）

1. `packages/importer` 是否**已解析** `[[页名]]`（Obsidian 导入路径）——若有，**复用其解析器**，不要另造语法；
2. 是否已有 `link`/`backlink` 表或搜索侧支持（PM 侦察：`backlink|page_link|wikilink` 全仓命中 **0**）；
3. 页面**改名**时既有引用的现状（是否有改写/失效处理）；
4. `packages/editor` 现有 inline 装饰/节点体系（T36 教训：**inline style 会被协作回声重渲染抹掉**，承载要走**装饰或真实节点**，不许用临时内联样式）。

## 1. 必须做到（口径）

1. **输入即链接**：在编辑器输入 `[[` 弹出**页面自动补全**（键入即过滤标题；↑↓ 选择、Enter 确认、Esc 取消）；也支持语法直填 `[[页名]]` 与 `[[页名|别名]]`。
2. **链接渲染**：已解析链接渲染为可点文本（走既有 inline 样式体系，**不写死 hex**）；**未解析链接**（目标页不存在）用**可区分的弱化样式**显示。
3. **点击行为**：已解析 → 在**页签**里打开目标页（复用 T37 `openInTab`，同页不重复开）；未解析 → **新建该页并跳转**（Obsidian 式）。
4. **反向链接面板**：页面内提供「**反向链接**」区块，列出**引用了本页的页面**（页名 + **上下文片段**），点击可**跳到源块**；链接增删后**实时更新**。
5. **未链接提及**（第二批，若本单时间不足可登记不做）：正文出现本页标题但未加链接的段落。
6. **索引必须派生（derived），不得新增 op**：从块内容解析链接，维护**派生的链接表**随提交**增量更新**，并提供**重建**命令；一致性判据：`增量维护结果 == 全量重建结果`（必须断言）。
7. **改名/移动**：改名后旧链接**不得静默失效**（保持可解析并给出可读状态）；**自动批量改写**列为第二批并登记。
8. **隐私**：全本地派生，零外呼（不引入任何网络行为）。

## 2. 验收（数值化/真机）

1. `[[` 补全：输入 2 字 → 候选列表含目标页（断言候选数与命中项）；Enter 插入链接（断言块内文本）。
2. 链接解析：造 3 条链接（2 有效 + 1 未解析）→ 断言渲染状态 2 已解析 / 1 未解析。
3. 点击：有效链接 → 目标页在页签打开（断言 active tab）；未解析 → 新页创建且跳转（断言页数与当前页）。
4. 回链：A 页引用 B 页 → B 页反向链接列出 A（**含上下文片段**）；删除该链接 → 回链实时消失（断言条数 1→0）。
5. **派生一致性**：随机插删 10 次链接后，`增量结果 == 全量重建结果`（断言完全相等，贴数值）。
6. 重开应用：链接渲染与回链**逐条还原**。
7. 回归：全仓无红；窗口零滚动、侧栏完全收起、手柄装订线 `gutter>=8`、对比度门禁、多页签（T37）、AI 面板（T38）、字段（T40）、Wiki（T42）行为不变。
8. 双主题 × 四态截图。
