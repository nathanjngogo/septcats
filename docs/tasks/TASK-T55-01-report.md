## 3. 定稿资产（全部可一键复跑）

```
node scripts/gen-icon-3dpix.mjs all   # 三变体 SVG（内嵌连通性质检，碎块≠1 即退出码 1）
node scripts/gen-icon-3dpix.mjs T     # 16px 原生托盘子型 SVG
node scripts/generate-pixel-icons.mjs # 全套 PNG（16/24/32/48/256 全档原生直画）
node scripts/build-pixel-ico.mjs      # .ico 五层组装（纯 stdlib）+ build 下 icon/tray PNG
```

- `scripts/pixel-png.mjs`：SVG→任意分辨率**原生直画**渲染核心（`rasterizeAt`，供 ico/预览/后续复用）。
- 判读定案分数：**C（正面坐姿+左立尾）=8 → 默认接线版**；B（正面大头）=7.5；A（侧坐全身）=6 淘汰候选（正头侧身视角矛盾+尾身粘连，判读原话）。
- 三选一决策区：老板如想换 **B**（大头版，小尺寸更稳）只需 `build-pixel-ico.mjs` 里把 C 字样换 B 重跑两脚本——assets README（T55-02 落）会写成一行的具体形态。
- 程序断言（PM 亲跑，原始值）：15 张 PNG 全档 **半透明像素=0、全纯灰 R=G=B**；`icon.ico` 五层 `[16,24,32,48,256]` 逐层 PNG 签名+IHDR 宽一致 ✓（2856 B）。
