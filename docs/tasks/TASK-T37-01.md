# TASK-T37-01 · R1：编辑区多页签（分页显示 + 快速切换页面）

> PM：Hermes ｜ 优先级 P1（老板新需求 R1）｜ 前置：T36-01 收口
> 老板确认：「分页显示」= **页面多页签**（Notion 式）；顺序 A→B→C

## 0. 目标与范围

在**顶栏下方、编辑区上方**加**标签条**，让用户同时打开多个页面并秒切。

**必须做到**：
1. **同一页不重复开**：所有打开页面的入口统一走一个「openInTab(pageId)」——侧栏行点击、搜索/面板命中跳转、模板新建后选中、回收站恢复后打开，**全部**走它。
2. 标签条交互：点击切换 · `×` 关闭 · 中键关闭 · 拖拽排序 · 溢出时横向滚动（不换行）· 当前标签高亮（用既有 `surface-active` 等 token）。
3. 键盘：`Ctrl+W` 关当前 · `Ctrl+Tab` 下一个 · `Ctrl+1..9` 跳第 N 个（与既有 `Ctrl+K` 不冲突）。
4. **持久化（本机 UI 状态，不进账本）**：标签集合 + 当前选中项 + 标签顺序，写 localStorage（与既有主题偏好同范式），**重开应用恢复**；工作区变化时按 workspace 隔离（不同 workspace 各自一套标签，切换工作区不串）。
5. 关闭当前标签 → 回落到**相邻**（右侧优先，无右侧取左侧）；全部关闭 → 编辑区走**既有空态**（`.pv-empty`）。
6. 标签标题随页面改名实时更新；未命名显示「未命名」；标题过长省略号。
7. 关闭标签**不等于删除页面**（不得触发删除/回收站逻辑）。

**不做**：多窗口、分屏对照、标签分组、预览浮层。

## 1. 验收（数值化/真机）

1. 开 5 个标签 → 乱序点击切换 → **重开应用**后：标签集合、顺序、当前选中项**全部还原**。
2. 同一页从 3 个入口（侧栏 / 搜索命中 / 模板新建）打开 → **只产生 1 个标签**且该标签被选中。
3. `Ctrl+W` 关当前 → 回落到相邻（断言选中项=右邻；无右邻=左邻）；全关 → `.pv-empty` 出现。
4. `Ctrl+1..9` / `Ctrl+Tab` 生效（断言选中项变化）。
5. 拖拽排序生效且**顺序被持久化**（重开后顺序一致）。
6. 关闭标签**不影响**页面存在性（断言 `pages` 列表与回收站计数不变）。
7. 双主题 × 四态（默认/hover/active/focus）截图；`no-magic`、`build-tokens --check` 通过。
8. 回归红线：**窗口零滚动**（T30）、**侧栏可完全收起**（T30）、**手柄装订线 gutter≥8**（T33）、**对比度门禁**（T34）全部保持。
