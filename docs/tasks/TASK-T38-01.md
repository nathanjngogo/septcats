# TASK-T38-01 · R2：AI 对话框（右侧可收起面板 · 多轮对话）

> PM：Hermes ｜ P1（老板新需求 R2）｜ 前置：T37-01 收口（`b141001`，rc.12）
> 老板口径：「AI部分应该要有对话框」+ 已确认「**可收起、放右侧**」

## 0. 目标与范围

在右侧加**可收起 AI 对话面板**：多轮对话 + 上下文取当前页 + 引用带出处 + 历史持久化；与既有「动作式 AI」并存。

**必须做到**：
1. **面板**：右侧栏，可收起/展开；收起后主区自动变宽；**状态持久化**（重开保持）；顶部标题 + 清空历史 + 关闭；与右侧既有 AI 动作面板（若存在）统一为一个 AI 侧栏（Tab 或分区），不要出现两个 AI 面板。
2. **多轮对话**：消息列表（用户/AI 气泡，走既有 token 与圆角/间距体系）+ 输入框（Enter 发送 / Shift+Enter 换行）+ 生成中可**停止** + 错误可读（复用既有 AI 错误口径）。
3. **上下文 = 当前页**：发送时把当前页标题 + 块文本按**预算截断**注入；提供「**附带选中内容**」开关（有选区时默认开）；**引用带出处**：AI 回复中引用页面内容时，展示「页名 › 块锚点」，**可点击跳转**（复用标签/选中机制跳到对应块）。
4. **历史持久化**：按 workspace 隔离（与 `septcats.tabs.<ws>` 同范式），上限 N 条（建议 200，超出丢最旧）；清空按钮生效；**不进账本**（不是笔记内容）。
5. **隐私硬不变量（必须成立，不得放宽）**：云端默认关；**对非本地端点，无 consent 时 fetch 零调用**；密钥只进 CredentialStore（**不进 localStorage/日志/同步包**）；AI 日志不打印消息正文。
6. **入口**：顶栏 AI 按钮 + 命令面板命令（打开/关闭 AI 对话）+ 快捷键 `Ctrl+J`。
7. **不做**：不做多会话管理（一个 workspace 一条历史即可）、不做附件上传、不做 @引用其它页。

## 1. 验收（数值化/真机）

1. **多轮上下文**：第 3 轮能正确引用第 1 轮的结论（真机用本地 LM Studio 跑 3 轮，贴对话截图/文本）。
2. **引用可跳转**：点击引用 → 跳到对应页/块（断言目标块进入视口或成为选中块）。
3. **历史持久化**：重启应用后历史逐字还原；清空后为空。
4. **隐私**：构造「非本地端点 + 未 consent」场景 → **断言 fetch 调用次数 = 0**（打桩/监听计数，报告贴数值）；断言 localStorage 与日志中**不含任何密钥**。
5. **面板状态持久化**：收起 → 重启 → 仍收起。
6. 键盘可达（Tab 焦点、Enter 发送、Esc 收起）、双主题 × 四态、`no-magic`、`build-tokens --check` 通过。
7. **回归红线**：窗口零滚动、侧栏可完全收起、手柄装订线 `gutter ≥ 8`、多页签（T37）行为不变、对比度门禁。

## 2. 红线

- 允许动：`apps/desktop/src/renderer/src/**`（AI 面板/状态/入口）、`apps/desktop/src/main/ai/**`（**只增不改**：如需 `chat` 模式/流式，新增而不改既有动作语义）、`apps/desktop/src/shared/**` 与 `preload`（仅新增 AI chat 通道名）、`apps/desktop/test/**`。
- 不碰：`packages/**`（含 `DESIGN.md`；若确需新 token 先报告等 PM 裁决）、`main/**` 其它模块、CI/发布脚本。
- 不加依赖（流式用既有 fetch/SSE 能力；无则先报告）；不碰 git；禁占位符/TODO；既有测试断言语义不变（需调整 §DEVIATION 逐条）。
- UI 红线：CSS 只走 `var(--sc-*)`、无字面 hex、无非 1px 重复裸 px、图标只从 `@septcats/ui` 出口、双主题四态齐备。
