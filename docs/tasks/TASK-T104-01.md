## 不变量（不得破）
1. `item.textContent` 仍是纯中文标签（`.nav-rail__label` 视觉隐藏但留在 DOM）——既有断言与真机探针按文本取标签，零改动。
2. 导轨宽度仍 `--sc-layout-rail`（56px）、八项顺序不变、`aria-current` 高亮单真源不变、键盘 Tab 序不变。
3. 选中态图标自动吃 `on-accent`（描边走 `currentColor`，不另写色）。
4. 组件 CSS 零字面 hex、非 1px 裸 px 不重复（no-magic 门禁）；不写裸 `border*` 直声明（框线纪律）。

## 环境侧收获（写进 skill）
- Linux 主机跑本仓 jsdom 门禁必须 `NODE_OPTIONS=--no-experimental-webstorage`（或 `--localstorage-file=<path>`）：node 26 内建 `localStorage` 会抢走 jsdom 的，症状是 `localStorage.clear()` undefined → 上百用例整片红（**假红**，非回归）。
