## 范围（纯前端，B1 后端零改动；若发现 B1 缺口 → 停，报告写清，不许私改 main 侧）
1. **加锁/解锁入口**（侧栏行 ⋯ 菜单 + 右键菜单同款 items，对照 T64 分体钮先例）：
   - 未锁页：菜单出「添加密码锁」→ Dialog：口令两栏（显示/隐藏 eye 钮）+「恢复码将由我保管」必勾确认 → `lock.setPass` → 成功后弹**恢复码展示框**（等宽大字+「我已抄写保存」确认钮才可关；禁复制按钮之外的静默丢失路径；文案明写恢复码只显示这一次）。
   - 已锁页：行前出像素锁 glyph（LucideLock 像素族既有则复用，无则 16 网格局部自绘）；菜单出「修改口令」「移除密码锁」（移除=口令验证 Dialog）。
2. **锁屏页**（编辑列位，替代 .pv-root 内容；侧栏/顶栏/标签条照常）：
   - 居中小卡：锁 glyph + 页标题 + 口令输入（Enter=验证，blur 不提交——口令类例外，守全局 blur 口径的例外要记 DEVIATION）+ 失败提示含剩余次数；
   - lockedUntil 生效时倒计时禁用输入（秒级，本地时钟仅展示，判定以主进程返回码）；
   - 「使用恢复码」折叠区：20 字节 base32 输入（自动大写分组）+ 新口令两栏 → `lock.recover` → 成功 toast+换口令语义。
3. **打开锁页的路径统一**：侧栏/搜索/收藏/最近/命令面板/页签恢复——全部走既有 openInTab→PageView 挂载时 `lock.getStatus`，locked 且会话未解锁 → 渲染锁屏卡（不请求 blocks）。搜索已锁页内容不出现（B1 已保证密文无 FTS），锁页**标题**可被搜到——结果行带锁 glyph（标题明文=总任务书限制声明，UI 要让用户明白）。
4. **i18n 双份**（zh 禁词门禁自查）+ 命令面板两条（add-lock/remove-lock 仅对当前页可见，学 fullWidth 条件项）。
5. **红线**：组件 CSS 全 `var(--sc-*)`、框轮廓一律 ink-edge（pixel-borders 全仓扫，workbench 灰线教训在前）；口令输入框 `type=password`、值绝不进 localStorage/日志（grep 自查）；恢复码展示框关闭前禁其他导航弹层叠它（§16 Dialog 纪律）。
