> 以下契约=**B1 实交付的 preload/shared 形状（PM 已 grep 核对，直接可用）**：
> - `window.septcats.lock.getStatus({pageId}) → {locked, failures, lockedUntil}`（未锁页也返回 `{locked:false,failures:0,lockedUntil:null}`，不抛错）
> - `.setPass({pageId, pass}) → {recoveryCode}`（一次性明文，关掉即无）
> - `.verify({pageId, pass}) → {ok:true}`；错→抛 `code: message` 字符串（`E_LOCK_BADPASS` / `E_LOCK_LOCKED`=限速中 / `E_LOCK_NOT_SET`）
> - `.recover({pageId, code, newPass}) → {ok:true, recoveryCode}`（恢复码一次性，返回**轮换后的新码**=必须再展示一次）
> - `.changePass({pageId, oldPass, newPass}) → {ok:true}`；`.remove({pageId, pass}) → {ok:true}`

## 范围
0. **读路径接线（B1 遗留，先做这条）**：`blocks:list` 主进程路由接 lock service 的 `readBlocks(pageId)`：
   - 未锁页走原实现（不给每页加 getStatus 开销——readBlocks 内部单查即可）；
   - 锁页且会话未验证 → 返回 `{locked:true, blocks:[]}`；
   - 会话已验证（verify/recover 后）→ 解密返回明文块。
   - `SeptcatsBlocksApi.list` 返回类型现为 `Promise<Block[]>`——扩为 `{blocks: Block[], locked?: boolean}` 形态（或带 locked 可选字段），取最小改动并守 renderer 既有消费方兼容。
   - 编辑器 commit 路径：已解锁页正常写明文（B1 的 encryptAndStoreBlocks 只在 setPass 时执行一次，无持续加密，勿改此语义）。
   - 配套单测：锁页 list 返回 locked:true；verify 后 list 出明文且字节=基线（把 B1 真机探针 SKIP 的 L4-b/L4-c 语义升级到测试层）。
1. **加锁/解锁入口**（侧栏行 ⋯ 菜单 + 右键菜单同款 items，对照 T64 分体钮先例）：
   - 未锁页：菜单出「添加密码锁」→ Dialog：口令两栏（显示/隐藏 eye 钮）+「恢复码将由我保管」必勾确认 → `lock.setPass` → 成功后弹**恢复码展示框**（等宽大字+「我已抄写保存」确认钮才可关；明写"只显示这一次"）。
   - 已锁页：行前出像素锁 glyph（pixelIcons 已有 Lock 像素族则复用，无则建局部 glyph 或申请豁免——**禁改 pixelIcons 主文件**，t58 先例）；菜单出「修改口令」「移除密码锁」（移除=口令验证 Dialog）。
2. **锁屏页**（编辑列位，替代 .pv-root 内容；侧栏/顶栏/标签条照常可用）：
   - 居中小卡：锁 glyph + 页标题 + 口令输入（`type=password`；Enter=验证；**blur 不提交=口令类全局例外，报告记 DEVIATION**）+ 失败提示含剩余次数（getStatus.failures）；
   - `E_LOCK_LOCKED` 或 lockedUntil 生效 → 输入禁用+秒级倒计时（展示用本地时钟，判定以主进程返回码为准）；
   - 「使用恢复码」折叠区：恢复码输入（自动大写分组）+ 新口令两栏 → `lock.recover` → 成功→展示新恢复码→进内容。
   - **锁屏态下编辑器彻底卸载**（不 mount ProseMirror，不请求 blocks）——B1 真机抓到锁定期编辑器 flush 竞态（明文块删后 flush 落新明文块），UI 卸载是根修。
3. **打开锁页路径统一**：侧栏/搜索/收藏/最近/命令面板/页签恢复——全走既有 openInTab→PageView 挂载时 `lock.getStatus`；locked 且未解锁 → 渲染锁屏卡。搜索：锁页**标题**可命中（结果行带锁 glyph），正文永不出（B1 已保证）。
4. **i18n 双份**（zh 禁词门禁自查；锁词条 en/zh parity）+ 命令面板两条（add-lock/remove-lock 条件项仅对当前页可见，学 fullWidth 先例）。
