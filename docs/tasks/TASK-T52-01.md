# TASK-T52-01 · P1：布局融合（标签条并入编辑区 + 侧栏通高至菜单栏 + 折叠钮搬家）

> PM：Hermes ｜ 工程师：CBL ｜ 前置：**T51-01 收口后**派发（同仓串行）｜ 老板 09-21 原话：「4. 分页应与编辑区融合。5. 左侧边栏的高度应该贯穿直到触碰菜单栏，左侧边栏隐藏键应在编辑区分页上方靠左。」

## 0. 侦察事实（PM 已定位 + 视觉模型判读，勿重复调查）

- 现结构（`App.css` rc.26 截图判读证实）：顶栏 `.app-bar` **通栏横切整个窗口宽度**；侧栏 `.app-side` 从**顶栏下方**（y≈46）起、到窗口底；折叠按钮在**顶栏最左**（x≈28,y≈23）；标签条 `.tabs-bar` 独立一行、自有 `surface-active` 底色，与编辑区白底 `.pv-root` 视觉脱节。
- 布局文件群：`App.tsx` / `App.css`（`.app-main-row` flex: `.app-side` + `.app-editor-col`）；`packages/ui/src/AppShell.{tsx,css}`（T30-01 红线：**AppShell props API 不得改**，只许折叠列宽/高度约束——本单如需改结构优先在 desktop 侧做）；`tabs/TabsBar.{tsx,css}`。
- 「菜单栏」= 窗口最顶端**原生菜单**（T51-01 刚本地化的那条）。即侧栏顶端要顶到原生菜单下沿，不再被通栏顶栏压住。

## 1. 必须做到（目标结构 ASCII）

```
┌─ 原生菜单栏 ────────────────────────────────────────┐
├─ 侧栏(通高) ─┬─ 顶栏 app-bar（只覆盖右侧，不再通栏）─┤
│ 个人工作区    ├─[≡]─ 标签1│标签2│标签3 ─────── + ─────┤ ← 折叠钮≡在标签行**最左**
│ 新建/收藏…   │           编辑区 pv-root              │
│ 回收站(底部) │                                       │
└──────────────┴───────────────────────────────────────┘
```
1. **侧栏通高**：`.app-side` 顶端触到原生菜单下沿（跨过原顶栏行），底端不变；工作区名（现顶栏左侧「个人工作区」）**移进侧栏头部**，顶栏只剩右侧功能区（搜索/AI/同步/新建/设置）。
2. **折叠钮搬家**：从顶栏最左 → **标签条行最左**（一个 24px 图标位），语义不变（收起后侧栏宽 0，钮仍可达——收起态时钮在编辑区左上，注意 T30-01「完全收起=0px」红线不破）。
3. **标签条与编辑区融合**：去掉 `.tabs-bar` 独立底色带，改为——活动标签白底与 `.pv-root` **连通无缝**（底部无分隔线穿过活动标签），非活动标签沉到 `surface` 灰底；标签行与编辑区之间不再出现横贯整行的硬分隔线（活动列「冒泡」进编辑区）。参照 Notion 无 tab 时的干净感 + Chrome tab 的连通感折中：**活动 tab 与正文同色、无边角断裂**。
4. **零滚动红线**：以上全部改动后 `document.scrollingElement` 仍零滚动（四宽度复验）；块手柄装订线 `.pv-body` 70px + gutter=12 不得被碰（T33/T36 红线）。
5. 双主题截图（浅/深 × 有标签/无标签/侧栏收起 三态 = 6 张）进 `docs/mockups/screens-t52/`。

## 2. 数值化验收

真机 CDP 断言：① `.app-side` 的 `getBoundingClientRect().top === 0`（相对内容区顶，即顶到菜单栏下沿）；② 折叠钮中心 x 在标签条行内（`tabsBarRect.left ≤ btnCenter ≤ tabsBarRect.left+64`）且 y 与标签行中心差 ≤2px；③ 活动标签底边与 `.pv-root` 顶边**无可见分隔线**（computed border-bottom=none 或同色覆盖，贴两元素背景色值）；④ 四宽度零滚动；⑤ 侧栏收起=0px。全仓 test 无红 + typecheck 9/9 + 双门禁。
