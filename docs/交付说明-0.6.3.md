## 二、逐条验收步骤（编号，照做即可）

1. **主题总览**：打开 设置 → 外观。第一行「配色派系」应有 **6 个**单选（默认/纯黑/高对比/纸感/石板/苔青），第二行「质感风格」应有 **3 个**单选：**像素**、**Linear 极简**、**毛玻璃**。
2. **毛玻璃**：点「毛玻璃」→ 整窗立刻变化（顶栏/侧栏半透明 + 背景虚化；菜单/弹层/命令面板更明显的玻璃质感）。
3. **Linear 极简**：点「Linear 极简」→ 框线收细到 1px、按钮出现圆角与柔影（与像素风的硬边对比明显）。
4. **持久化**：选好一个主题 → 完全退出应用 → 重开：主题仍在（`data-look` / `data-palette` 从本地存储恢复）。
5. **画廊确实没了**：顶栏（右上角图标排）不再有调色板/画廊按钮；设置页没有「打开画廊」字样；命令面板（Ctrl+K）里搜「画廊」无结果。
6. **浅色下的「纯黑」**：浅色主题下「纯黑」置灰不可点（与旧画廊同口径）；切到深色主题后可选并生效。
7. **批量删除**：侧栏「批量删除…」→ 进入多选（行首出现勾选框；**点整行 = 勾选**，不会跳转页面）→ 勾几页 → 计数变化 → 点「全选」全勾、点「清空」全消、按 Esc 退出多选。
8. **批量删除执行**：「删除所选」→ 二次确认弹层（写明项数）→ 确认后：这些页进回收站、**只弹一条**汇总提示（如「已移入回收站 3 项」）、多选计数归零。
9. **父子同选**：同时勾父页与其子页 → 确认后只删一次（子树一次带走），提示项数按实际删除项计。
10. **取消**：确认弹层点「取消」→ 什么都没删。

## 三、诚实说明

- **macOS**：本机是 Windows，DMG 只能由 CI 产出；且你已决定不买 Apple 签名 → mac 端自动更新为**手动下载**态（设置里给「前往下载页」）。Windows 端自动更新正常。
- **CI**：主仓已转 public（Actions 免费）；此前四腿 failure 是账户付费额度问题（runner 0 steps），非代码问题。发布链走 `gh release`，不依赖 Actions。
- **H-06 挂账**（未治）：`page_link_index`/`mention` 不在重建清表清单里 → 重建后双链索引可能与投影不一致；排为下一轮首项。
- **本地 perf 指标**（commitOps P95 ≤16ms）长期贴阈值：本轮静默复跑全绿，先前 16.2/17.9ms 系并行跑批时的 CPU 争用；CI 侧已是量级哨兵。
