## 0. 版本与数据格式决策（必须先对齐）

| 项 | 决定 |
|---|---|
| 版本 | `0.3.0`（在 rc.23 基础上仅改版本号，无代码变更） |
| **DB 迁移版本** | **v9**（migrations 1–9：v8=`page_type`/`summary`，v9=`page_link_index`） |
| **op-log 段格式** | **v3**（`SCHEMA_VERSION=3`，**自 0.2.0 起未变**） |
| 兼容 | `MIN_SUPPORTED_SCHEMA_VERSION = 1` → **v1/v2/v3 段均可读**；新写入一律 v3 |
| **升级窗口（关键）** | 0.1.4（v1）用户**不能**直接升 0.3.0 后与旧同步文件夹混跑：**先升 0.2.0，再升 0.3.0**。单机用户无感 |
| 双设备（G5） | 两端**必须同版本**（都 0.3.0）；混版本会把新格式段隔离 |
| 一句话结论 | **段格式未变 → 无新的跨端兼容风险**；DB 迁移是本地行为、逐版自动执行 |

## 4. 发布说明（中英双版草稿）

### 中文

> **版本 0.3.0**
> 这一版按你的七条需求（R1–R7）把 Septcats 从「能记笔记」推到「能当第二大脑用」。
> **新增**
> - **多页签**：像浏览器一样开多个页面、拖动排序、关闭恢复
> - **AI 对话面板**：右侧可收起的多轮对话，上下文取自当前页；**本地模型优先，零外呼**
> - **布局设计器**：Notion / 专注 / 工作台 三预设一键切换，可微调侧栏宽度、正文宽度、AI 面板位置、密度、主题，支持导入导出

> - **「数据库」改称「多维数据」**，字段体系大修：单选/多选可管理选项、字段可改类型（值不静默丢）/ 可删除（列值一并清理）/ 可左右排序，标题字段受保护
> **改进**
> - 编辑器内容真正落库；侧栏真实页面树（新建/重命名/折叠/收藏/最近/回收站）
> - 回收站完整可用：删除 → 恢复 / 彻底删除（二次确认）
> - 搜索 1–2 字中文也能命中，可直接跳转；面包屑显示真实层级
> - 全部文案本地化，深浅主题对比度达标
> **升级提示**
> - 数据格式升级（DB 迁移至 v9，**op-log 段格式仍为 v3，多设备兼容性不变**）
> - **从 0.1.4 直升的用户请先升到 0.2.0 再升 0.3.0**；多设备同步请保证两端版本一致
> - 回退旧版前请先备份数据根目录

## 5. 老板冒烟（装包后 8 步）

1. 覆盖安装 → 打开，侧栏应有你自己的页面树
2. 新建页 → 输入一段中文 → **关掉应用重开** → 内容仍在
3. Ctrl+K 搜 2 字中文 → 命中并可跳转
4. 打开两个页面（多页签）→ Ctrl+K 切「布局预设」→ 观察侧栏宽/正文宽/AI 面板即时变化
5. 页面「⋯」→ **转为 Wiki** → 侧栏出现 Wiki 分区与落地页 → 建两个子页 → 索引应显示 2 条 → 再转回普通页
6. 另一页输入 `[[` → 选一个页面 → 出现链接 → 点它应跳转 → 目标页应有**反链**显示来源页
7. 新建一个多维数据页 → 加一个「单选」字段 → 在单元格里新建选项并选值 → 改字段类型 / 左右移 / 删字段各试一次
8. 设置 → 外观 → 语言切 English → 界面全英文 → 切回中文；主题切深色看对比度

## 6. 回滚方案

- 应用回滚：安装回 rc.22/rc.23 安装包；**回滚前备份数据根**
- 发布回滚：`gh release edit latest` 指回上一版资产（feed 的 `latest.yml` 决定更新目标）
- 数据回滚：本版**不修改既有段文件**（只追加 v3 段），故备份即可回退；DB 迁移为本地追加列/表，不破坏旧数据
- 构建清理：`git worktree remove _scratch/release-0.3.0`
