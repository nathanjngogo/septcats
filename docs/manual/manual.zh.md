# Septcats 使用说明书

版本对应 0.6.x ｜ 本地优先的笔记应用

## 快速上手

1. **新建第一篇笔记**：按 `Ctrl+N`（或菜单「文件 → 新建页面」），编辑区立即出现空白页。
2. **写内容**：直接输入文字；行首输入 `/` 唤出斜杠命令菜单，可插入标题、列表、代码块、表格等块。
3. **不用保存**：Septcats 自动保存你的每一次编辑——防抖落库、关窗时还会最后冲刷一次。随时放心关窗。
4. **找东西**：按 `Ctrl+K` 打开命令面板，可搜索页面、执行所有命令（切换主题、打开设置等）。

第一次启动会引导你创建「工作区」——你的笔记按工作区隔离存放，全部保存在本机，不上传任何数据。

## 页面与标签

- 页面在左侧边栏以树形组织，可新建子页面形成多级结构；每行的「⋯」菜单提供全宽切换、普通页 ↔ Wiki 页互转与删除；双击标题进入重命名。
- **重命名**：在侧栏树标题上输入新名字后，**点别处（失焦）即生效**，按回车同样生效，按 `Esc` 取消。
- **多标签页**：每打开一个页面顶部多一个标签；`Ctrl+W` 关闭当前标签（不会关应用窗口）；标签上悬停显示关闭按钮。
- **收藏与最近**：侧栏「收藏」「最近」提供两个快捷视图。
- **删除与回收站**：删除的页面进入「回收站」（菜单「文件 → 回收站」），可恢复或彻底删除。

## 块编辑器

- **斜杠命令**：行首输入 `/` 后接关键字过滤块类型（标题、待办、代码、表格、分割线……）。
- **Markdown 快捷**：支持 `#` 标题、`-` 列表、`> ` 引用等输入即转换；从外部复制 Markdown 粘贴会自动识别格式。
- **双链**：正文中输入 `[[页面名` 会联想已有页面，选中即建立双向链接；链接目标页的「反向链接」区能看到引用来源。目标不存在时可选择「新建并链接」——这是搭建个人 Wiki 的基础。
- **全选/撤销**：`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做，编辑冲突自动合并（多人协作场景基于 CRDT）。

## 数据库视图

页面内可插入「数据库视图（Db View）」块，把子页面当表格管理：

- 表格网格支持文本、数字、复选框、日期、单选、多选等属性列。
- 单元格内直接编辑：数字格输入数值、勾选格空格/回车切换、复选框点击即改。
- 支持按列排序、筛选视图；修改同样自动保存。

## 搜索与命令面板

- **搜索页**：侧栏或菜单进入，全文检索所有工作区页面，命中片段高亮。
- **命令面板**：`Ctrl+K`。输入任意关键词模糊匹配命令（新建页面、切换主题、打开设置、AI 续写/总结/重写/翻译、同步、导入导出……）。

## 模板

- 把任意页面「另存为模板」（命令面板 `保存为模板` 或页面菜单），之后在「模板」区一键以模板为骨架新建页面。

## 导入与导出

- **导入**：菜单「文件 → 导入」或顶栏 ＋ 按钮进入导入向导：支持批量导入 Markdown 文件夹，自动建页面与目录结构。
- **导出**：命令面板 `导出`，将当前工作区页面导出为 Markdown 文件包——你的数据永远可以完整带走。

## 同步（可选）

默认**完全离线**。在设置 → 同步中自行开启后，可在多台设备间同步同一工作区（端到端凭据仅存本机密钥库）。同步按钮六态显示于顶栏：未开启 / 等待 / 同步中 / 已同步 / 离线 / 错误。

### 把同步接到网盘（分步）

Septcats 自己**不联网传输**——跨设备搬运交给网盘客户端，你只需三步：

1. 装好任一网盘客户端（夸克网盘 / 百度网盘等），登录，确认它的「同步目录」已在工作
   （如 `D:\BaiduSyncdisk\` 或夸克的自动同步文件夹）。
2. 打开 Septcats 设置 → 数据与隐私 → 「同步路径」点 **更改…**，选中网盘的同步目录
   （建议在其下新建专用子文件夹，如 `BaiduSyncdisk\Septcats`，不要选网盘根目录）。
   确认对话框后按提示**重启 Septcats** 生效。
3. 在第二台设备装同样网盘、登录同一账号、同步到同一子目录，再在 Septcats 设置里
   把同步路径指过去并开启同步开关——两台设备就会经由网盘悄悄对齐，互相不需要知道对方 IP。

注意：更换同步文件夹**不会搬移旧数据**，新文件夹将从「首设备」重新开始同步；
旧文件夹里的内容请自行清理。同步进行中托盘菜单顶部会实时显示状态行
（待传 N / 同步中 / 已同步 / 出错）。

### 图片和附件也会跟过去

开启同步后，页面里引用的图片 / 文件（附件）会经同步文件夹的 `files/` 目录自动在
后台同步——另一台设备追平后即可看到，无需任何手动操作。引擎自带护栏：大文件流式
分块搬运（不卡内存）、磁盘将满自动暂缓、传输失败自动退避重试、**只增不删**（附件
不会因页面删除而在网盘上被清掉，腾空间用设置 → 数据与隐私 的「清理未引用附件」）。
托盘状态行与同步面板的「待传 / 同步附件」数字含附件口径。

若同时开启「加密同步段」，附件也会分块加密后落 `files/`；中途开关加密会自动按
新形态补传，两台设备混用的旧明文文件照收（内容以校验和复核，安全不减）。

### 端到端加密与恢复码

设置 → 同步里可开启「加密同步段」：同步文件夹里的内容全部以 AES-256-GCM 加密后落盘，
网盘和任何中间人看到的都是密文。钥匙只存在你本机的系统凭据库里。

- **恢复码**：开启加密后请到 设置 → 同步 → 「导出恢复码」，抄存到**离线**的安全地方
  （密码管理器/纸张）。换机或重装系统后用「导入恢复码」找回同步能力。
- **⚠️ 密钥丢失警告**：恢复码是唯一备份，**丢了 = 同步文件夹里的历史数据永久不可读**，
  本机数据不受影响，但无法再与新设备合并。请导出后立即妥善保管。
- 「轮换钥匙」可作废旧恢复码并生成新的（后台重加密，完成后须重新导出保存）。

## 数据与存储维护

你的全部数据都在一个**数据文件夹**里（默认 `C:\Users\<用户名>\.septcats`，可迁移）：
SQLite 主库 + 附件目录 + 日志，没有不可见的隐藏状态。

- **换电脑迁移（推荐：便携包）**：旧机 设置 → 数据与隐私 → 「导出便携包」得到单个 zip
  （主库+同步段+附件完整打包）；新机双击该 zip 或在设置里「导入便携包」，向导会引导
  完成换机——这是**逐字节保真**的迁移，双链、锁页、附件全在。Markdown 导出适合只搬
  内容的轻量场景。
- **清理空间**：设置 → 数据与隐私 提供两块清理：「数据库墓碑清理」回收删除页面留下的
  历史墓碑；「清理未引用附件」先预览（只读零删除）再确认执行，近 30 天的文件与
  锁页盲区一律扣留不碰——宁多勿漏。
- **备份**：关闭 Septcats 后整目录复制数据文件夹即成完整备份（含 WAL 文件，勿单拷
  `septcats.db` 一个文件）。

## AI 助手（可选）

- 顶栏 ✦ 按钮开合 AI 侧栏（位置可在布局设置中改为底部或隐藏）。
- 支持「对话」与快捷动作：续写、总结、重写、翻译（选中文字后从命令面板发起）。
- **隐私**：默认云端功能关闭；推荐接本机 LM Studio / Ollama（设置里填 `http://127.0.0.1:1234/v1` 这类本地端点即可）。任何云端端点都必须你显式同意后才会有请求发出。密钥只进系统凭据库。

## 设置

顶栏齿轮按钮打开设置页，四大分区：

- **外观**：主题（浅色 / 深色 / 跟随系统）、配色派系（六套中性配色）、**质感风格**（像素 / Linear 极简 / 毛玻璃，与配色和明暗互不干涉，整窗即时换肤）、语言（简体中文 / English / 跟随系统）。切换语言即时生效，原生菜单栏同步翻译。配色与质感都在「打开画廊」里点卡即换。
- **布局**：见下一章。
- **AI**：端点、模型名、密钥（存凭据库）、云端开关。
- **关于**：版本号、检查更新（应用内自动更新，走官方源）、回滚上一版本。

## 布局与窗口

- **三套预设**：Notion 式（侧栏+编辑区）、专注式（隐藏侧栏、窄正文）、工作台式（宽正文+AI 常驻）。
- **侧栏**：标签行最左侧的折叠按钮收起/展开；宽度可拖拽或设置中调整；侧栏从菜单栏下方一直贯通到窗口底部。
- **全宽切换**：菜单「视图 → 切换全宽」让正文占满窗口，适合宽表格与数据库页。
- **关窗行为**：点窗口 ✕ 会弹出询问框——「最小化到托盘」应用继续在后台驻留（托盘图标左键呼回窗口）；「退出」真正关闭。勾选「记住我的选择」后不再询问（设置可改回）。**无论选哪项，未保存的编辑都会先自动落库**，绝不吃数据。
- **托盘右键**：显示主窗口 / 退出。

## 常见问题

- **换电脑怎么迁移？** 旧机「导出」Markdown 包 → 新机「导入」。数据永远是你的文件。
- **更新失败？** 设置 → 关于 里可回滚到上一版本；日志在数据目录（默认 `C:\Users\<用户名>\.septcats\logs`，macOS/Linux 为 `~/.septcats/logs`）。
- **AI 不回复？** 检查设置 → AI 的端点是否在线（本地跑 LM Studio 需确认服务已启动）；错误提示会给具体原因而不是裸错误码。
- **误删页面？** 回收站里可恢复。
